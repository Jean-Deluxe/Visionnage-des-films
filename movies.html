Liste des films

Cette page affiche une liste de films avec leurs affiches, réalisateurs et titres. Les données sont extraites de Wikidata en utilisant une requête SPARQL. Vous pouvez voir les résultats directement sur cette page grâce à l'iframe ci-dessous.

voici la requête SPARQL utilisée :

        
            #defaultView:ImageGrid

            SELECT DISTINCT ?film_poster ?director ?directorLabel ?film ?filmLabel ?title WHERE {

            ?film wdt:P31 wd:Q11424;

                wdt:P3383 ?film_poster;

                wdt:P1476 ?title.

            ?film wdt:P136 wd:Q1054574.

            ?film wdt:P57 ?director.

            SERVICE wikibase:label { bd:serviceParam wikibase:language "[AUTO_LANGUAGE],en". }

            }

            LIMIT 100
